Conformidade com a LGPD

Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018)

Importante: Este é um produto fictício de demonstração. O site CNPJ Fácil não é uma empresa real, não coleta dados pessoais e não realiza tratamento de dados nos termos da LGPD.

1. Dados pessoais tratados

Este site não coleta, armazena, processa ou compartilha dados pessoais conforme definidos no Art. 5º, I da LGPD. As consultas de CNPJ são processadas localmente no navegador com dados simulados.

2. Base legal

Não há tratamento de dados pessoais e, portanto, não se aplica nenhuma das bases legais previstas no Art. 7º da LGPD. O único armazenamento local (tema visual) é realizado com consentimento implícito do usuário ao utilizar o toggle de tema.

3. Direitos do titular

Nos termos do Art. 18 da LGPD, o titular de dados pessoais tem direito a:

  • Confirmação da existência de tratamento;
  • Acesso aos dados;
  • Correção de dados incompletos ou desatualizados;
  • Anonimização, bloqueio ou eliminação;
  • Portabilidade dos dados;
  • Eliminação dos dados tratados com consentimento;
  • Informação sobre compartilhamento;
  • Revogação do consentimento.

Como nenhum dado pessoal é coletado, todos os direitos acima são naturalmente garantidos.

4. Encarregado (DPO)

Por se tratar de um projeto fictício, não há encarregado de proteção de dados (DPO) designado.

5. Segurança

A página adota Content Security Policy (CSP) para prevenir ataques de injeção e proteção contra clickjacking (frame-ancestors: none). Por não transmitir dados a servidores externos, não há risco de interceptação ou vazamento de dados de consulta.

6. Cookies e armazenamento local

Apenas a preferência de tema (claro/escuro) é armazenada via localStorage. Nenhum cookie é utilizado. Consulte a Política de Privacidade para detalhes.
