Política de Privacidade

Última atualização: 16 de junho de 2026

Importante: Este é um produto fictício de demonstração. O site CNPJ Fácil não é uma empresa real, não oferece serviços comerciais e não coleta dados pessoais de usuários.

1. Dados coletados

Este site não coleta, armazena ou transmite dados pessoais de qualquer natureza. As consultas de CNPJ realizadas na página são processadas inteiramente no navegador do usuário, utilizando uma base de dados simulada (mock). Nenhuma informação de consulta é enviada a servidores externos.

2. Armazenamento local

A única informação armazenada no seu dispositivo é a preferência de tema visual (claro ou escuro), utilizando o mecanismo localStorage do navegador. Este dado:

  • Não contém informações pessoais;
  • Não é transmitido a terceiros;
  • Pode ser removido a qualquer momento limpando os dados de navegação do site.

3. Cookies

Este site não utiliza cookies de rastreamento, cookies de sessão ou quaisquer outros mecanismos de identificação de usuários.

4. Links externos

Esta página não contém links para sites externos. Todos os links são internos e fazem parte do projeto de demonstração.

5. Direitos do titular (LGPD)

Como este é um projeto de demonstração que não coleta dados, os direitos previstos na Lei Geral de Proteção de Dados (Lei nº 13.709/2018) são naturalmente respeitados. Não há dados a serem acessados, corrigidos, portados ou excluídos.

6. Contato

Por se tratar de um projeto fictício, não há canais oficiais de contato. Este site existe exclusivamente para fins de demonstração de interface e funcionalidades.

7. Alterações

Esta política pode ser atualizada para refletir mudanças na demonstração. Alterações serão publicadas nesta página.
